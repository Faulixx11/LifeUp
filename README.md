# LifeUp
**Your life, in flow.**

A personal workspace prototype for capturing, organizing and following through on tasks, projects, documents and life-admin processes.

## Current
- Overview dashboard with stats, quick capture and activity
- Tasks: create, complete, delete, search, filter
- Projects: create and increment progress
- Inbox: capture notes, links, ideas, reminders
- Life Admin: track personal processes
- Document entries (metadata only; file storage not implemented)
- AI Agent and Memory screens as roadmap placeholders
- Browser local persistence and JSON backup

## Run
Open index.html in a modern browser. No build step required.

## Roadmap
1. Refine core UX/data model
2. Real file uploads and document processing
3. Backend, accounts and secure sync
4. AI model integration and agent orchestration
5. Carefully scoped integrations and approved actions
6. Reminders and monitoring

**Prototype note:** Data currently stays in the current browser's localStorage. No cloud sync, AI connection, authentication or integrations are implemented yet.
